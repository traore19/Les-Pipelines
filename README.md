# 📌 Les-Pipelines

## 📖 Description
Ce projet présente la mise en place et l'utilisation de **pipelines de traitement de données** en Python.  
L’objectif est d’automatiser les étapes essentielles d’un workflow de Data Science :  
prétraitement, transformation, encodage et préparation des données pour l’entraînement de modèles.

---

## 🎯 Objectifs du projet
- Comprendre le fonctionnement des **pipelines**
- Automatiser les étapes de nettoyage et transformation des données
- Réduire les erreurs lors du prétraitement
- Préparer efficacement les données pour l'entraînement de modèles ML

---

## 🛠️ Technologies utilisées
- **Python**
- **Pandas**
- **NumPy**
- **Scikit-learn**
- **Jupyter Notebook**
